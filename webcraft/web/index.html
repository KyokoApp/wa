RustCraft

Voxel sandbox — engine Rust → WebAssembly + renderer WebGL2 dengan shader pack
Game orisinal terinspirasi Minecraft. Tidak berafiliasi dengan Mojang/Microsoft.
Dibangun dengan Rust (WASM), meshing + ambient occlusion, dan shader GLSL.

Pengaturan

Kontrol

WASD / Panah — Bergerak
Mouse — Lihat sekeliling (klik untuk kunci kursor)
Space — Lompat / Naik saat terbang
Space 2× / F — Mode terbang (creative)
Shift — Jongkok / Turun saat terbang
Ctrl / R — Sprint
Klik kiri — Hancurkan blok
Klik kanan — Pasang blok
1–9 / Scroll — Pilih slot hotbar
E — Inventaris (semua blok)
F3 — Panel debug
Esc — Pause

Sentuh (HP / tablet)

Joystick kiri — Bergerak
Drag kanan — Lihat
Tap — Pasang blok · Tahan — Hancurkan
Tombol — Lompat, terbang, sprint, dll.
